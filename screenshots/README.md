# Weather App — Screenshots

This folder contains screenshots demonstrating the user interface and functionality of the Weather App.

## Screenshots Included

* **Weather Homepage:** Shows the city input field and Check Weather button.
* **Weather Results:** Displays the selected city, temperature, weather description, wind speed, and weather icon.
* **Error Handling:** Demonstrates the error message displayed when a weather request fails.

These screenshots illustrate the application's user interface, API integration, and weather information display.

## Technologies Used

* HTML5
* JavaScript
* Bootstrap 5
* OpenWeather API
